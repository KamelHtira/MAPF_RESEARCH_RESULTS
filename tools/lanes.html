One-way lanes tool

Load a map and see the one-way lanes the PIBT planner puts on it. A 1-wide corridor cell has walls on both sides. The columns that hold vertical corridors are numbered from left to right and the rows that hold horizontal corridors from top to bottom, and neighbouring streets get opposite directions. A lane is dropped again if it would cut cells off from the rest of the map (for example a dead end). The tool runs the same rules as the planner (applyStreetLanes).
